you run the program with 'python TaskTrackerCLI.py [command]'
here is the command list:
1) add [task name]: adds a task
2) list: shows task list and info
3) strt [task name]: starts task and updates status to todo
4) cmplt [task name]: marks task as finished and updtates status to completes
5) del [task name]: deletes the task
6) clr: clears all tasks
